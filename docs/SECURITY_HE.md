# אבטחה ופרטיות

- Argon2 לסיסמאות; JWT קצר-חיים ואסימון רענון.
- RBAC בצד השרת לארבעה תפקידים.
- הצפנת תעודת זהות ו-HMAC לחיפוש; אין כתיבת מזהה מלא ללוג.
- CORS מוגבל, כותרות אבטחה, ORM פרמטרי ושגיאות מובנות.
- יומן ביקורת לאירועי גישה ושינוי עם סינון סודות.
- סודות מגיעים ממשתני סביבה בלבד.

לייצור יש להשתמש במנהל סודות, TLS, סבב מפתחות, גיבויים מוצפנים, ניטור, בדיקות חדירה ומדיניות שמירת מידע מאושרת.
