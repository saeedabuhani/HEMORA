# סקירת הפרויקט

HEMORA היא מערכת תמיכת מידע לימודית לניהול, הסבר והשוואה של בדיקות דם. היא מיועדת למטופלים, קלינאים, עובדי מעבדה ומנהלים. הסיווג הקליני אינו משתמש במודל שפה: הוא דטרמיניסטי, ניתן להסבר, תלוי יחידות וטווחי ייחוס, מתועד בגרסה וניתן לביקורת.

המערכת אינה מאבחנת מחלה ואינה מכשיר רפואי מאושר. הנתונים לדוגמה בדויים לחלוטין.
