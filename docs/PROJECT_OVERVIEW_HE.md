# סקירת הפרויקט — HEMORA

**Understanding change. Protecting health.**

## מה זו HEMORA

מערכת Full-Stack בעברית וב-RTL לניהול, ניתוח, השוואה ומעקב אחר בדיקות דם
לאורך זמן. זהו אב־טיפוס לימודי של מערכת תומכת החלטה קלינית
(Clinical Decision Support).

**המערכת אינה מאבחנת מחלות ואינה מחליפה איש מקצוע רפואי.**

## הבעיה

מטופל שמקבל תוצאת בדיקת דם מקבל טבלה של מספרים. גם כשמסומן שערך חורג,
קשה להבין: האם זה השתנה מאז הבדיקה הקודמת? לאיזה כיוון? האם המצב משתפר?
ומה בכלל הבסיס לקביעה שהערך חריג — הרי טווחי הייחוס משתנים בין מעבדות,
בין גילים ובין מטופלים.

## מה המערכת עושה

1. שומרת מטופלים והיסטוריית בדיקות דם
2. מסווגת כל תוצאה מול טווח הייחוס המתאים לה
3. מסבירה כל מדד בעברית פשוטה
4. משווה כל בדיקה חדשה לקודמת — מדד מול מדד
5. מזהה שיפור, החמרה, יציבות, חריגה חדשה או חזרה לטווח
6. מציגה מגמות לאורך זמן
7. מבדילה בין נתון חסר לנתון חריג
8. מסבירה לכל ממצא בדיוק על מה הוא מבוסס
9. מפיקה דוח PDF בעברית

## ארבעת התפקידים

| תפקיד | רואה |
|---|---|
| **מנהל מערכת** | הכול — כל המטופלים, ניהול הקטלוג, יומן ביקורת |
| **רופא** | רק את המטופלים המשויכים אליו |
| **מרפאה** | רק את המטופלים השייכים למרפאה שלה |
| **מטופל** | את התיק שלו בלבד |

ההפרדה נאכפת בשרת, בשתי פונקציות מרכזיות, ולא בהסתרת כפתורים בממשק.

## מה מייחד את המערכת

**שקיפות מלאה.** לכל ממצא יש כפתור "למה HEMORA מציגה את זה?" שפותח הסבר
מלא: הערך, הטווח, מקור הטווח, הערך הקודם, ההפרש, וכלל ההשוואה שהופעל.

**סיווג דטרמיניסטי, לא AI.** אותם נתונים יביאו תמיד לאותה תוצאה, וכל ממצא
ניתן להצדקה. הניתוח נשמר עם גרסת אלגוריתם.

**השוואה קלינית ולא אריתמטית.** "השתפר" נקבע לפי התקרבות לטווח הייחוס,
לא לפי עלייה או ירידה במספר.

**זהירות ביחידות.** אם אין המרה דטרמיניסטית מאושרת בין שתי יחידות,
המערכת מסרבת להשוות ומסמנת `NOT_COMPARABLE`.

**חוסר בנתונים אינו חריגה.** בדיקת CBC ללא HGB מטופלת כמידע חסר,
לא כממצא רפואי.

**אין ציון בריאות.** יש ציון *איכות נתונים* בלבד, עם הבהרה מפורשת
שאינו מדד בריאות.

## מחסנית טכנולוגית

| שכבה | טכנולוגיות |
|---|---|
| Frontend | React 19, TypeScript, Vite, Tailwind, React Router, TanStack Query, Recharts |
| Backend | Python 3.12, FastAPI, SQLAlchemy 2, Pydantic v2, Alembic |
| מסד נתונים | SQLite (פיתוח) / PostgreSQL (Docker) |
| אבטחה | Argon2, JWT + refresh, RBAC, Fernet, HMAC |
| דוחות | ReportLab + python-bidi (עברית RTL) |
| בדיקות | pytest, Vitest, React Testing Library, Playwright |
| הרצה | Docker, docker-compose |
