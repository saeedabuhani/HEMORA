# תכנית בדיקות

בדיקות יחידה מכסות תעודת זהות ישראלית, סיווג תקין/נמוך/גבוה/קריטי, טווח חסר, המרות יחידה, השלמת פאנל וסינון Audit. בדיקות API מכסות התחברות והרשאות. בדיקות רכיב מאמתות סטטוסים והצהרת בטיחות. Playwright מכסה את מסך הכניסה ומהווה בסיס לתרחישי ההדגמה המלאים מול Docker Compose.

לפני מסירה: `pytest`, `npm test`, `npm run build`, העלאת API, migration, seed ו-`docker compose config`.
