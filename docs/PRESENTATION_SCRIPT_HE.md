# תסריט הדגמה — 5–7 דקות

שלום, זה HEMORA — מערכת שעוזרת להבין שינוי בבדיקות דם לאורך זמן, בלי להחליף רופא ובלי לאבחן.

אני נכנס כקלינאי עם חשבון הדגמה. בלוח הבקרה רואים מטופלים ובדיקות. כל הנתונים כאן בדויים ומסומנים DEMO DATA.

אני פותח מטופל עם בדיקה ראשונה. במסך הבדיקה המערכת מציגה כמה מדדים בטווח, כמה חריגים ומה איכות הנתונים. לכל מדד רואים ערך, יחידה, טווח ומקור הטווח. בבדיקה הראשונה מופיע שאין עדיין בסיס להשוואה.

עכשיו אפתח את הבדיקה השנייה. ההשוואה נעשית מדד מול מדד. שיפור אינו רק מספר שעלה: המנוע בודק אם הערך התקרב לטווח הייחוס. אפשר לראות גם מעבר מתקין לחריג וחזרה לטווח.

בגרף רואים שלוש בדיקות לאורך זמן, ללא ניסיון לנבא מחלה. אצל מטופל אחר CBC חסר HGB. המערכת לא קוראת לזה חריגה; היא מבקשת לבדוק את דוח המעבדה המקורי.

מכאן אפשר להפיק PDF בעברית. בתצוגה המקצועית רואים מקור טווח, איכות, יחידות וגרסת אלגוריתם.

מאחורי הממשק יש React, FastAPI ו-PostgreSQL. המנוע הקליני דטרמיניסטי, מוסבר ומבוקר. תעודת הזהות מוצפנת, החיפוש נעשה ב-HMAC, הרשאות נאכפות בשרת וכל פעולה חשובה נרשמת ביומן ביקורת.

לסיום, HEMORA היא אב-טיפוס לימודי של מערכת תמיכת מידע — לא מכשיר רפואי ולא תחליף להחלטה מקצועית.
