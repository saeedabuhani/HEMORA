# מדריך משתמש

1. התחברו באמצעות חשבון הדגמה.
2. בחרו מטופל. כל הרשומות המסומנות `DEMO DATA` בדויות.
3. פתחו בדיקה כדי לראות סיכום, איכות נתונים, תוצאות, מקור טווח והמלצות.
4. החליפו בין תצוגת מטופל לתצוגה מקצועית.
5. הוסיפו בדיקה ידנית או העלו CSV באשף הייבוא. הייבוא אינו נשמר לפני אישור.
6. לאחר בדיקה שנייה מוצגת השוואה; לאחר שלוש בדיקות מוצגת מגמה.
7. הורידו דוח PDF מהבדיקה.

בכל ספק רפואי יש לפנות לאיש מקצוע רפואי ולהסתמך על דוח המעבדה המקורי.
